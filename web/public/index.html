How it works

The cube is stored as a bitboard — one 64-bit word per face, eight bits per sticker — so a turn is a handful of shifts and masks. IDA* searches it depth-first, guided by a pattern database holding the exact distance-to-solved for all 100,179,840 corner configurations, packed at 4 bits each via Lehmer-code ranking. Because that heuristic never overestimates, the first solution found is provably optimal.

The desktop build fans the search across every CPU core for an 8–10× speedup; this page runs single-threaded, since shared-memory threads need response headers GitHub Pages can't set.
